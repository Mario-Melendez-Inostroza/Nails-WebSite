# Vibras + nails

Sitio web de **Vibras + nails**, espacio de belleza y bienestar en San Bernardo, Santiago, con reservas por WhatsApp.

**Sitio en vivo:** https://nails-web-site.vercel.app/

## Secciones

- Inicio, Servicios, Galería, Nosotros y Contacto
- Reserva directa por WhatsApp

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Despliegue en Vercel

## Cómo ejecutarlo

```bash
npm install
npm run dev      # servidor de desarrollo
npm run build    # build de producción
```
